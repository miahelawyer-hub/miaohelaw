咨询里最常听到的一句话是：*婚都离了，担保自然作废。* 法律上不是这样。

新移民离婚的身份、移民监、家暴保护，我们另有一篇[总览](/blog/new-immigrant-divorce-ontario/)。这一篇只把**担保书本身**讲清楚：它管多久、管什么、政府怎么追、它和家庭法上的抚养费差在哪里。

---

## 担保配偶移民后离婚，担保书还有效吗？

有效。配偶移民担保书（undertaking）是担保人与政府之间的合同，不是与被担保配偶之间的合同。婚姻破裂、分居、离婚，都不会使担保书终止。

《移民与难民保护条例》（IRPR, SOR/2002-227）第 132 条规定的担保期限，在您签字时就已经固定。之后婚姻发生什么，都不改变它。

## 配偶移民担保的期限是多久？

**3 年，自被担保人成为永久居民之日起算。**

起算点经常被算错。不是结婚之日，不是递交申请之日，也不是登陆加拿大之日——除非登陆当日同时获批 PR。IRPR 第 132 条的截止点是：成为永久居民之日起三年期间的最后一天。

其他类别差别很大：

| 被担保人类别 | 担保期限 |
|---|---|
| 配偶 / 同居伴侣 / 婚姻伴侣 | 3 年 |
| 22 岁以下受抚养子女 | 10 年，或至该子女满 25 岁（以先到者为准） |
| 22 岁及以上受抚养子女 | 3 年 |
| 父母 / 祖父母 | 20 年 |

如果您同时担保了配偶和其前段婚姻的未成年子女，子女那部分的责任可能远远长于配偶部分。离婚谈判时这一条经常被忽略。

## 担保责任具体包括什么？

担保书承诺的是基本生活需要（basic requirements），通常包括食物、衣物、住所（含水电）、日常生活用品，以及公费医疗未覆盖的医疗和牙科费用。

它**不包括**律师费、学费、汽车、投资，也不是要您维持对方原来的生活水准。家庭法上的配偶抚养费另有自己的标准，见[安省配偶抚养费与 SSAG](/blog/ontario-spousal-support-ssag-imputed-income-misconceptions/)。

## 如果对方领了社会救助，我要还钱吗？

要——前提是救助确实发在担保期内。

在安省，被担保人在担保期内领取 Ontario Works 或 ODSP，省政府可以向担保人追偿已发放的款项。这是担保债务（sponsorship debt），实务后果包括：

- 省政府可以采取民事执行措施追讨
- 债务清偿前，您不能再担保任何人移民（包括新配偶、父母）
- 债务不会因为离婚、再婚或搬去别的省而消失

不是对方一申请救助您就自动欠钱。只有实际获发、且落在担保期内，追偿才成立。

这也修正了另一篇里容易说太满的一点：想[担保父母](/blog/new-immigrant-divorce-ontario/)时，离婚本身通常不取消资格，但**未结的担保债务会卡住新的担保申请**。

## 离婚会让对方失去永久居民身份吗？

不会。

加拿大在 2017 年取消了有条件永久居留。被担保配偶一旦取得 PR，不再需要与担保人共同居住来维持该身份。婚姻破裂本身不是撤销 PR 的理由。

例外是虚假婚姻：如果 IRCC 有证据表明该婚姻自始就是为移民目的而虚构的，可以启动调查并可能影响身份。真实婚姻后来破裂，与自始虚假，是两件事，举证标准也不同。单纯「只维持了一年就离婚」并不等于虚假婚姻。

何淼律师办理的是家庭法，不是移民法申请。身份、虚假陈述、撤回担保这些事项，需要同时咨询持牌移民顾问或移民律师。家庭法这边要做的，是把担保书从分居协议和抚养费里分开处理，避免签出对您不利、却又约束不了政府的条款。

## 如果 PR 还没批下来就分手了怎么办？

必须通知 IRCC，双方都有这个义务。

配偶类申请的基础是关系真实且持续存在。关系在审批期间终结却不告知、继续以配偶身份获批，可能构成《移民与难民保护法》下的虚假陈述，后果远比申请被拒严重，包括最长 5 年的入境禁令。

担保人可以在 PR 批出前撤回担保。一旦 PR 已经批出，就不能再撤回。

## 担保义务和配偶抚养费是一回事吗？

不是。两套制度并行：

| | 移民担保书 | 配偶抚养费 |
|---|---|---|
| 法律依据 | IRPR s. 132 | 《离婚法》/ 安省《家庭法》第三部分 |
| 对谁负责 | 加拿大政府 | 前配偶本人 |
| 期限 | 固定 3 年（配偶类） | 依据婚姻长度、收入差距、SSAG 等因素 |
| 能否协议免除 | 不能 | 可以（须符合有效性要求） |
| 能否变更 | 不能 | 可以（情况有实质变化时） |

关键差别：担保书不能通过[分居协议](/family-law/domestic-contracts/)免除。您和前配偶签的任何协议都对政府无约束力，因为政府不是协议当事人。协议能不能被推翻，见[分居协议签了还能反悔吗](/blog/separation-agreement-validity-ontario/)。

反过来，担保书也不自动产生家庭法上的抚养义务——它不是配偶抚养费的替代品，也不是免除理由。两项可能同时存在。

## 担保期内我该做什么？

实务上三件事值得做：

1. **保留担保书副本和 PR 批准日期。** 3 年的起算点全靠这个日期，很多人事后找不到了。
2. **在分居协议里写明担保书的存在。** 协议不能免除对政府的义务，但可以约定：若对方申领社会救助导致担保债务，对方须向您赔偿（indemnity）。这在协议层面通常可执行。
3. **担保期结束、且确认没有未结担保债务之前，不要急着做新的担保申请。**

## 常见问题

### 离婚了，移民担保还要继续吗？

要。担保书是与加拿大政府之间的合同，离婚不影响其效力。配偶类担保期为对方成为永久居民之日起 3 年，期满自动结束。

### 担保期是从结婚那天算还是从登陆那天算？

都不是。从对方成为永久居民之日起算 3 年（IRPR 第 132 条）。如果是境内申请，通常是 PR 批准函上的日期。

### 我和前配偶在分居协议里写明互不追究，担保书就无效了吗？

不能。协议只约束签约双方，而担保书的相对方是政府，政府不受该协议约束。但可以在协议里加入赔偿条款，约定若因对方申领救助产生担保债务，由对方补偿您。

### 前配偶领了安省社会救助，我会收到账单吗？

有可能。省政府可以就担保期内发放的社会救助向担保人追偿。在该债务清偿前，您无法再担保他人移民。

### 离婚会让我的前配偶被遣返吗？

不会。加拿大自 2017 年起已取消有条件永久居留，被担保配偶取得 PR 后不需要共同居住来维持身份。只有在婚姻自始虚假并经 IRCC 认定的情况下才可能影响身份。

### 担保期内我搬去别的省，担保还算数吗？

算。担保书是与联邦政府订立的（魁北克有独立制度），搬迁不影响担保期或担保内容。
